What waste is it?

Every activated part is eventually removed for good. Where it can go depends on its waste class, and the class can hang on a trace element nobody thought about. This chapter classifies a steel block and finds that element.

A 50 kg steel support block sat much closer to the plasma than the bracket: five years in a field 500 times stronger. It's the same steel, SS316 with 0.1% cobalt, plus 0.05% nitrogen and 0.01% niobium. Now it has to go.

This chapter uses the United States rules for burying radioactive waste near the surface, called 10 CFR 61.55, which ACTINV ships as a ready-made rule pack. They sort waste into classes:

Class AThe least radioactive. The simplest disposal.
Class BNeeds a stable form that keeps its shape for 300 years.
Class CAlso buried deeper or behind a barrier, against someone digging into it.
Above class CNot allowed near the surface at all. Few places will take it.

All numbers come from actinv impurities with waste-class endpoints, and from a full run of the block. Other countries' rules differ; the idea is the same.

Step 3 of 7

How a class is decided

The rules list nuclides in two tables, each with a concentration limit. For each nuclide you divide how much there is per cubic metre by its limit, then add up the fractions. That sum of fractions decides the class.

  • Table 1 holds the long-lived nuclides, the ones that stay for thousands of years. Sum above 1: above class C. Above 0.1: class C at best.
  • Table 2 holds shorter-lived ones, with a column of limits for each class.

          What ACTINV does differently
          
The waste class as something you design for. ACTINV classifies a result against a rule pack, and its impurity screen tells you how each trace element moves the class, the worst steel the certificate allows, and so which impurity to limit when you buy the steel. Every nuclide's half-life and type come from the decay data, so you don't type them in.

          
The class is the nominal U.S. classification. Whether a site accepts the waste is a separate question.

Learn ACTINV

A course in ACTINV, step by step: make something radioactive, guess what happens, then run ACTINV and read the answer.

Each chapter is one engineering question, worked out with real ACTINV results you can explore. Every technical word has a short definition you can click, and nothing needs to be installed to follow along. Each chapter shows the desktop app, the command line and Python side by side, so you can use whichever suits you, and ends with the problem file to run yourself.

# Documentation

The curated public handbook starts at [Welcome to ACTINV](guide/index.md). Its navigation is maintained in [guide/SUMMARY.md](guide/SUMMARY.md), and `book.toml` builds only that source directory.

Release procedures, defect investigations, maintainer notes, and historical evidence remain in this repository. They are linked from the handbook where relevant and are not automatically published as chapters or added to handbook search.

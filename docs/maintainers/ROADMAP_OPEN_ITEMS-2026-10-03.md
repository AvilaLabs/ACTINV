The planned initial phase is still unopened and unhashed. Its scope is nominal, single-component U.S. 10 CFR 61.55 classification and verified Class A/B/C impurity budgets. The supporting scope and proposed gates are in [ROADMAP.md](../ROADMAP.md#planned-extension--component-waste-classification-and-material-impurity-budgets-2026-10-03) and [WASTE_CLASSIFICATION_EXTENSION.md](../WASTE_CLASSIFICATION_EXTENSION.md).

The named technical dependencies are already available:

- **P75b composition linearity:** the coupled/reach arm passed with maximum aggregate error `1.06e-11`; trace/reach failed (maximum `0.506`). Therefore any material-composition superposition in this feature must force coupled mode and reach pruning; do not infer that trace mode is valid. Evidence: `results/p75b_summary.md`, `results/p75b_verdict.json`, `protocols/ACTINV-P75B_PROTOCOL.md`.
- **P79/P79a `budget`:** both protocols and verification gates are complete. The command solves pure elements, composes table response linearly, handles balance-element gradients and limit/status cases, then re-solves the declared mixture and emitted limits. Evidence: `docs/BUDGET.md`, `crates/actinv-cli/src/budget.rs`, `results/p79_verdict.json`, `results/p79a_verdict.json`, `results/p79_budget_eurofer97.json`, `results/p79a_budget_eurofer97.json`.

Reuse P79's spec resolution, coupled/reach configuration, prepared solve cache, per-element inventory collection, composition algebra patterns, and full-material edge re-solves. For the waste feature, the response evaluator must instead compute every applicable §61.55 table/column sum, keep constraints from separate columns/tables distinct, and derive the controlling class limit. Do not reuse clearance CI semantics as if they were Part 61 rules. Classification needs component mass/displaced volume, declared waste type, mesh-cell aggregation before concentration normalization, and separately declared external retained/fuel tritium. Unknown required inventory inputs must keep conclusions conditional or unknown.

Before freezing its protocol, G0 still needs primary-source verification of the selected rule pack, aggregate categories, activated-metal variants, table combination rules, units, and exact boundary interpretation. The fusion intrusion screen is a later separate gate: its draft-source version is unresolved, including the recorded Cs-137 `460` versus regulation `4,600` discrepancy and table numbering. Do not let that screen delay the nominal current-rule phase.

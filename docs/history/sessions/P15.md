## What changed

ACTINV now prepares two deterministic, self-validating artifacts automatically on first use:

- `actinv-prepared-library-1` retains exact binary64 nonzero spans and original row metadata for selective groupwise
  reads; and
- `actinv-collapsed-spectrum-1` binds those rows to the exact flux and group-boundary bits used by the ordinary
  one-spectrum path.

Both formats bind the source library and index SHA-256 identities, validate fixed-width dimensions, offsets, counts,
and a whole-artifact integrity trailer, and publish through a completed temporary sibling plus same-filesystem rename.
An existing corrupt, stale, truncated, trailing, cross-source, or cross-schema artifact fails closed and is never
silently overwritten. Concurrent creators either produce the same bytes or validate and reuse the winner. Deleting
the cache is supported and changes only preparation cost.

The public production library contains 167,735 rows over 709 groups. The control compared all 167,735 row
descriptors, all 710 boundary values, all 33,597,258 retained cross-section values, and all 167,735 spectrum-collapse
values bit-for-bit. There were zero mismatches. The prepared artifact is 275,493,400 bytes, 28.96% of the original
951,392,920-byte dense `sig` payload; its accompanying collapsed artifact is 6,888,807 bytes. Empty-cache creation
took 5,582.67 ms at 129,626,112-byte peak RSS and wrote 282,382,207 bytes. Deletion and recreation produced the exact
same artifacts and normalized result.

Indexed empty, Fe, fixed noncontiguous, and all-target selections reproduce the verified source rows in original
order and stay within the frozen selected-payload-plus-16-MiB allocation bound. The CLI and Python entry points
produce the same normalized result hash and use the same Rust-owned cache; Python adds about 17.55 MiB over the CLI,
not a second activation payload. Uncertainty deliberately retains its already verified dense path where exact
original-row covariance mapping is required.
